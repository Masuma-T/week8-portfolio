# Masuma Tahir — Week 8 Portfolio

This portfolio was migrated into a modern npm + Vite project using ES Modules. The JavaScript is separated into three modules: `projects.js` contains the project data, project card creation, and project rendering; `api.js` contains the GitHub API functions used to fetch and display repositories; and `main.js` imports the required functions and handles the DOM event wiring for project filters, search, and GitHub repository loading. The project uses Vite for development and production builds and is deployed through GitHub Pages.

* `src/style.css` — Portfolio styling
* `src/projects.js` — Project data and rendering
* `src/api.js` — GitHub API functions
* `src/main.js` — Application wiring
* `vite.config.js` — Vite configuration and GitHub Pages base path
